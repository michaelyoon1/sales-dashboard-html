# Sales Dashboard HTML

Static HTML dashboards generated from the sales analysis project.

## Files

- `index.html` - sales analysis dashboard
- `top_items_daily.html` - top-selling items per day dashboard
- `model_data.js`, `rank_position_data.js`, `top_items_daily_data.js` - local data used by the dashboards
- `dashboard_preview.png` - preview image

Open `index.html` in a browser to view the main dashboard.
